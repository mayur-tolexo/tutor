Read a line of text and count the vowels, consonants, uppercase letters and lowercase letters. Only alphabetic characters count; spaces, digits and punctuation are ignored. `y` is a consonant.

**Input:** one line.

**Output:** four lines:
```
Vowels: <n>
Consonants: <n>
Uppercase: <n>
Lowercase: <n>
```
