Read `n` numbers into a tuple and a target value. Print whether the target is present and how many times it occurs.

**Input:** first line `n`; second line `n` integers; third line the target.

**Output:** two lines:
```
Found: Yes
Count: <n>
```
or `Found: No` and `Count: 0`.
