Read a list of numbers and swap each element at an even index (0, 2, 4, …) with the element right after it at the odd index (1, 3, 5, …). If the list has an odd number of elements, the last one stays in place.

For `1 2 3 4 5` print `2 1 4 3 5`.

**Input:** first line `n`; second line `n` integers.

**Output:** the modified list on one line, space-separated.
